# End of assert() / NEO_AA_NullParamAssert() in LNAA

For a while I have not made new commits that use `asserts()` / `NEO_AA_NullParamAssert()`, as if we enounter an error, or another program calling libNeoAppleArchive functions, it should not lead to the stopped execution of the caller. Much of this code was made during the early stages of libNeoAppleArchive's development. While I have debated about removing the code, as I do not want to break anything using the library, I have made the decision to remove these asserts and instead "graciously" fail, and if a function is void and should detect so, make it an int that returns a error code. For functions such as `neo_aa_header_set_field_blob()`, this means not only are asserts removed, but that rather than being `void`, it now returns an `int` with 0 indicating success and 1 indicating failure. As these functions did not return anything to begin with, this should not break anything compiled before these changes or code functionality, as these functions did not return any value to begin with, hence I do not expect any breakage as nothing currently expects a return value from these functions anyway.

Future code containing the outdated `assert()` / `NEO_AA_NullParamAssert()` will not be excepted unless it is a extremely rare circumstance where a case can be made for it being needed.
